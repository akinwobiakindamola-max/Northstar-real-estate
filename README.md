# NorthStar Group website

Responsive static website built with HTML, CSS, and JavaScript.

## Preview
Serve the `dist` directory with any static web server:

```sh
python -m http.server 4174 --directory dist
```

Deploy `dist/` as the public directory.

## Hero video
`dist/assets/hero-video.mp4` plays muted, looping and inline. The image stays visible until playback begins. A pause/play button is included. Reduced-motion preferences use the still image by default.
